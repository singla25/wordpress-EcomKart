# 🛒 EcomKart — Custom WordPress E-commerce Theme EcomKart is a custom-built WordPress e-commerce theme developed from scratch, focusing on dynamic data handling, custom filtering logic, and clean theme architecture without relying heavily on third-party plugins. --- ## 🚀 Features - Custom WordPress Theme Development (No page builders) - Dynamic product listing using WordPress Loop - Custom Page Templates for structured layout - Dual Filtering System on a single page (independent filters) - AJAX-based interactions for better user experience - Optimized data fetching using WP_Query - Modular and reusable theme structure --- ## ⚙️ Tech Stack - WordPress (Core) - PHP - MySQL - JavaScript (AJAX) - HTML / CSS / Bootstrap --- ## 🧠 Key Concepts Implemented ### 1. Custom Theme Development - Built theme from scratch with proper file structure - Used functions.php, template hierarchy, and reusable components --- ### 2. Dynamic Data Rendering - Used WordPress Loop for displaying products dynamically - Implemented custom queries using WP_Query --- ### 3. Dual Filtering System (Core Feature 🔥) - Implemented two independent filters on the same page - Each filter works without affecting the other - Built custom query logic to handle filtering conditions - Implemented without using external plugins --- ### 4. Performance Optimization - Optimized queries for faster data fetching - Avoided unnecessary plugin dependencies --- ## 📁 Project Structure wp-content/ └── themes/ └── my-theme/ ├── assets ├── index.php ├── function.php ├── single.php └── index.php --- ## 🎯 Learning Outcomes - Deep understanding of WordPress theme architecture - Hands-on experience with WP_Query and custom filtering - Building scalable and maintainable theme structure - Handling dynamic frontend interactions using AJAX --- ## 🔗 GitHub Repository https://github.com/singla25/wordpress-EcomKart
